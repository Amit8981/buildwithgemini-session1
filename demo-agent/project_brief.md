# My agent: Smart Pantry Concierge
One-liner: A conversational agent that helps home cooks manage their pantry inventory and discover recipes based on available ingredients.

Tool coverage:
- Memory: User dietary restrictions, favorite cuisines, and household size
- Tools: Pantry inventory lookup (`get_pantry_items`), add/update pantry items (`add_pantry_item`), recipe search (`search_recipes`)
- Catalog/UI: Recipe cards and pantry inventory tables
- Image gen: Generating visual previews of suggested recipes
- Sandbox: Calculating recipe nutrition and scaling serving sizes

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: code sandbox for nutrition calculations
